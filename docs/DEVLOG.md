## 2026-11-28 — Phase 1: Foundation (milestone M1)

**Starting state.** The repository contained a single empty `test.txt` on both
`main` and the working branch. No "Prototype 01" ZIP was provided, so there
was no existing player prototype to repair. Phase 1 was built from scratch.
`test.txt` was left untouched (safe to delete whenever you like).

**Built**
- Godot project (`project.godot`), targeting Godot **4.7.2** (current stable).
  Forward+ renderer, physics interpolation on, 60 Hz physics.
- Full input map (WASD, Shift, Ctrl, Space, V, E, wheel, F3, Esc) using
  physical key codes.
- The folder structure from the master plan, with empty folders kept via `.gitkeep`.
- Player: `CharacterBody3D` with walk (2.0 m/s) / jog (4.5) / sprint (7.5),
  jump (≈1.28 m) with coyote time + jump buffer, heavier fall gravity, stamina
  with exhaustion lockout, body turns toward travel direction, respawn when
  falling out of the world, placeholder walking bob.
- Camera: third-person over-the-shoulder with SpringArm3D wall collision,
  mouse-wheel zoom, first-person mode, smooth 0.35 s blend between them (V),
  body hidden in first person, mouse capture/release.
- Nova City "Founders Cross" greybox: crossroads with lane markings and
  sidewalks, Downtown towers, mid-rise block, residential block with a park,
  and a Test Yard (jump boxes 0.5–2 m, 15°/30° ramps, 55° unclimbable slope,
  stairs, overhang, pillars, wall). Generated by a `@tool` script with a
  world-space grid shader.
- HUD: stamina bar, crosshair (first person), F3 debug panel, controls help,
  "click to capture mouse" hint.
- Automated test suite `tests/test_runner.gd` (51 checks).
- Docs: setup guide, architecture, this log, known bugs, feature tracker,
  Phase 2 plan.

**Verified (actually executed, Linux build of the same Godot versions)**
- `--import` and a 300-frame headless run of the main scene: 0 errors, 0 warnings.
- Opening `main.tscn` in the headless editor: 0 errors.
- Test suite on Godot 4.7.2: **51 passed, 0 failed** (exit code 0).
- Test suite on Godot 4.3: **51 passed, 0 failed** (see KNOWN_BUGS #2 for 4.3 shutdown noise).
- Test suite on a fresh clone (no `.godot` cache) after `--import`: 51/51.
- Mutation check: disabling the camera SpringArm collision makes the
  "camera stays below the overhang roof" test FAIL (camera y=4.36), confirming
  the tests detect real breakage.
- Rendered screenshots (OpenGL/Compatibility under a virtual display) of
  spawn, Test Yard, skyline, first person, ramps. Found and fixed heavy
  over-exposure (sun 1.25→1.0, ambient 0.9→0.5, darker palette) and an
  unreadable stamina label (added text outline).

**Not verified here (needs your PC)**
- Real mouse feel and sensitivity, real keyboard input, on-screen frame rate on
  your GPU, the Forward+ (Vulkan) renderer, and the Windows build itself.
  The container has no GPU and no Windows, so those must be checked by you
  using the checklist in the milestone report.

**Decisions**
- Target Godot 4.7.2 (what a beginner downloads today), but keep files 4.3-compatible.
- Stay on Godot Physics for now; evaluate Jolt in Phase 2 with vehicle measurements.
- No autoload singletons yet. Nothing needs global state so far.

**Next:** Phase 2 / M2: first drivable vehicle (see `docs/milestones/M2_FIRST_VEHICLE.md`).
